# Male-urological-cancers
Source code reveals core features of the article Integrating Multi-Omics Atlas to Uncover Genetic and Epigenetic Mechanisms and Reveal Cellular State Evolution Across Ecotypes in Male Urological Cancers

This folder (code folder) contains source code for reproducing the main figure and its supplementary figures.

In addition, thses section (CMR-schematic-diagram and CNV-affecting-ecotypes-Schematic folders) includes schematic diagrams of CMR and intercellular communication, which help to better illustrate the relevant results.

We also validated the identified transcription factor regulatory networks by performing in silico knockouts using scTenifoldKnk (Virtual—knockout folder).

We performed molecular docking analysis by batch-importing drug molecules and proteins. To ensure accuracy, we also conducted manual downloads and analyses; the results likewise indicate that the drugs can bind stably to the target genes (autodock-Verification folder).

We hope these code and diagrams prove helpful to you.
